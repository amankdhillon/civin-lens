# Body boundaries

Address matching checks a boundary file for each body. Name each file with the body's id from the `bodies` table, for example `bos.geojson`.

- Format: GeoJSON, Polygon or MultiPolygon. Coordinates are [longitude, latitude].
- Source: the official boundary file from the county, city, or school district, or Census TIGER files for federal and state districts.
- Keep files simplified and small.

Until a file exists, people can choose their bodies from the list instead.
